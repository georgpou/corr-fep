# corr-fep

Reproducible research on statistically reliable force-field-to-QM/MM free-energy endpoint corrections using targeted free-energy perturbation (TFEP).

Project setup and initial workflows are being prepared on a feature branch. The reference implementation is [the authors' reproducibility repository](https://github.com/andrrizzi/paper-alchemical-tfep-qmmm-2026); the underlying [tfep library](https://github.com/andrrizzi/tfep) is an external dependency.
